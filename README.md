Entry for the [One-Line Roast: The Gadget You Use Every Day bounty on make.fun](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

`main.ts` (Node 22, standard library only, deterministic, no network) writes one
original roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set).

The line:

> My phone dies at 4 p.m. every day like it has a union contract, then judges me for checking the battery percentage like I'm the unreliable one.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-gadget-out node main.ts
cat /tmp/roast-gadget-out/entry.txt
```
